- `bun run shortcut` makes a Windows Start Menu shortcut that opens Finnie in dev mode with no console, or focuses it if open.
- A phone layout (lists, chart, details under a tab bar) for narrow touch screens, and a web app manifest so it installs to a home screen.
- The dev server answers your tailnet as well as this machine, so a phone on Tailscale can open Finnie; other networks are refused.
- Pages sharing the settings file merge their edits instead of overwriting each other, and pick up each other's within 15 seconds.
